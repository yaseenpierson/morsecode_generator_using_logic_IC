# morsecode_generator_using_logic_IC
A hardware-based Morse code flashlight transmitter that converts button presses into timed LED flashes for dots and dashes. Built using NE555 timers, 74HC14, CD4017B, 74HC74, CD4066 switches, and a 2N2222A transistor, with no microcontrollers or development boards. Designed for potential laptop-camera-based Morse code decoding.
